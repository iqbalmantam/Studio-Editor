# Studio-Editor

Editor video berbasis web dalam satu file (`index.html`). Berjalan di browser desktop dan HP, bisa dipasang sebagai aplikasi (PWA) dan dipakai offline. Aplikasi: https://iqbalmantam.github.io/Studio-Editor/

## Fitur

**Edit klip**
- Split, trim, duplikat, geser, magnet, pilih banyak klip, ripple delete
- Kecepatan, speed ramp, putar mundur, freeze, stabilkan, volume, fade
- Keyframe (zoom, geser, putar, opasitas), mask, crop bebas, chroma key, blend
- Reframe otomatis (AI) dan hapus bagian diam
- Transisi, animasi masuk/keluar, filter, warna lanjutan, hapus latar (AI)

**Teks dan caption**
- Font, gaya, animasi, efek (hollow, gradasi, neon, bayangan panjang, melengkung)
- Caption otomatis (Whisper AI), impor/ekspor SRT, gaya caption, edit massal
- Trek teks di timeline

**Overlay**
- PiP multi-lapis, gambar, stiker emoji, bentuk dan bingkai berwarna
- Kolase dengan slot media

**Audio**
- Multi-trek, extract audio dari video, efek suara, pengurang noise, ducking, beat sync
- Ekspor audio MP4/M4A/MP3/WAV

**Proyek**
- Template (termasuk Produk), template sendiri, Brand kit (warna, font, logo)
- Magic resize (9:16, 16:9, 1:1, 4:5, 5:4), watermark
- Simpan otomatis, buka kembali tanpa pilih ulang media
- Ekspor MP4 H.264 offline per frame, atur frame rate dan bitrate

📖 Cara pakai singkat
  1. Tambah video lewat Proyek Baru atau tombol + Klip.
  2. Potong: geser playhead, tekan Split, pilih klip lalu Hapus. Seret tepi klip di timeline untuk trim.
  3. Presisi: tombol ＋ di samping waktu memperbesar timeline (atau cubit dua jari di HP).
  4. Percantik: tab Teks, Audio, Efek, dan Ukuran untuk caption, musik, filter, dan rasio.
  5. Ekspor: tab Proyek → ⚡ Ekspor cepat. Pilih kualitas: Kecil / Otomatis menjaga ukuran file mendekati aslinya. Biarkan tab tetap terbuka sampai selesai.

Pintasan (desktop): Spasi putar/jeda · S split · Delete hapus · ← → geser 1 dtk (Shift 0,1 dtk) · , . geser 1 frame · + − 0 zoom timeline · K tambah keyframe · Ctrl+Z / Ctrl+Y undo/redo

🔒 Video diproses di perangkat Anda dan tidak diunggah ke server. Draf tersimpan otomatis di browser ini; simpan proyek ke file untuk cadangan.
